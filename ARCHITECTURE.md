# AgentShield Architecture

## Vision

AgentShield is an Internet Trust Protocol.

AgentShield continuously establishes identity,
preserves memory, infers intent, computes trust,
and enables autonomous access decisions.

Core Flow:

Identity
↓
Memory
↓
Intent
↓
Trust
↓
Decision

---

## Core Principle

AgentShield does not evaluate requests.

AgentShield evaluates entities.

The primary entity of the system is Identity.

Requests are events generated by identities.

---

## Domain Model

Tenant
 ├─ ApiKey
 └─ Identity
      └─ Event

---

## Identity

Represents an internet entity.

Examples:

- Human browser
- API client
- AI agent
- Device
- Service account

---

## Memory

Memory is stored as Events.

Every interaction contributes to the history of an identity.

---

## Trust

Trust is computed from historical behavior.

Trust is not manually assigned.

Trust is earned or lost over time.

---

## Decision

Allow
Challenge
Block

Decisions are outputs.

Trust is the source.

---
